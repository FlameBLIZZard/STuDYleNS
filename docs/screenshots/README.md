# Screenshots

This directory is intended for high-quality screenshots of the StudyLens application.

When adding screenshots before the final hackathon submission:
1. Capture screenshots using the browser dev tools (responsive mobile mode, 480px width) or iOS/Android simulators.
2. Optimize the images (e.g., using TinyPNG or standard web optimization) so they don't bloat the repository.
3. Save them exactly as:
   - `1-dashboard.png`
   - `2-scan.png`
   - `3-detect.png`
   - `4-explain.png`
   - `5-practice.png`
   - `6-progress.png`
4. Commit them to this directory. The main `README.md` will automatically render them.
